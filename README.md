# HomeMCLobby

Lobby plugin for HomeMC, a Minecraft 1.8 server network I built in late 2025.

Everything a player touched before joining a game: navigator and warps, cosmetic gadgets,
pets, hats, launch pads, a shop, the scoreboard, the tablist, and build mode for staff.

## Where this went

The successor is [PRISMARIN](https://github.com/LeonManuel0705/prismarin), whose
`lobby-paper` module covers the same ground on modern Paper with a proper menu framework and
localisation instead of hardcoded German strings.

This repository is kept as it was. Archived.
